# Introduction to Back-End Development (DA559A)

My repo for the course. It started as a copy of the course template; this README is mine to change.

| Directory | Contents |
|---|---|
| [`exercise/`](exercise/README.md) | The exercises, week by week, updated from the template |
| [`doc/`](doc/README.md) | Articles and reading instructions, updated from the template |
| `src/` | The app I build week by week, with the tests next to the code |
| `public/` | Static files for the app: HTML, CSS, images |
| [`practice/`](practice/README.md) | Small exercises that stand on their own, one directory each |
| [`report/`](report/README.md) | My weekly reports |

`CLAUDE.md` (and `AGENTS.md`, which points to it) tells an AI assistant about this repo and how to help me learn.
